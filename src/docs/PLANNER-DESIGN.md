定位：`VIEWER-PLAN.md` 的 **S3 模块**独立设计文档。工程较大、需要反复讨论，采用**先敲定基础条件 → 再定模型 → 再选求解器 → 最后开发**的分阶段推进方式。
实现方案（Phase C/D 落地细节、候选池规则、模块拆分、验收）：**`PLANNER-IMPL.md`**。

## 0. 目标与边界

给一份 `galaxy.json`（S2 产物：恒星/行星/主题/矿脉/轨道）+ 一份配比需求（矩阵 10万/min + 戴森球），
输出**每颗行星承担哪些产品生产基地**，使总运输距离最小。

- 参考 Java 原型 `<本地 Java 原型（未随仓库发布）>` 的逻辑，**重新设计**（数据用我们的、模型重写、求解器重选）
- 规划结果写回 `galaxy.json` 的 `plan` 区块（S3 只写 plan，不碰其他区块）
- 与资源（矿脉储量）**无关**——选址不读矿脉，矿脉仅作展示数据保留在 veins 区块

### B2. 产量口径（均分）与槽内自用

- **不估计游戏实际产量**：每物品有唯一总需求 D_p（B1 推流结果），该物品有 n_p 个槽 → **每槽承担量 = D_p ÷ n_p**（均分，对称假设）
- **槽内自用（自动推导）**：同组内 A 是 B 的原料 → B 在本星消耗的 A 由本星生产（距离 0）；关系从 `recipes.csv` 自动推导（同组 + 成品-原料），不手工维护
  - 例 G9（磁线圈+磁铁，2 槽）：每槽磁铁 246,450、每槽磁线圈 244,800；磁线圈耗磁铁 244,800 本星自给；净余磁铁 1,650 外送
  - 例 G5（超磁环+涡轮+电机+齿轮，2 槽）：齿轮→电动机→电磁涡轮 链条本星自给
  - 例 G2（电磁+能量+结构，1 槽）：无内部供应链，三色全部外送到白糖槽
- **附属品只在主生产基地（槽 0）生产**：A1 钢/钛合金 → 铁块槽 0；A2 棱镜/光子合并器 → 玻璃（单槽）；A3 超磁环 → G5 槽 0
  - 附属品产量 = 全部需求（不按槽均分），其原料在槽 0 内自用（钢耗铁块等）
- **母星 G8**：六品 + 增产剂固定母星，不参与选址；G8 内部上下游距离 0，外部原料运入
- 槽位定义文件：`plan_slots.json`（槽 id/产品组/槽数/每槽承担量/附属品/组内自用链）

### B3. 净额模型、变量与约束

- **每槽每物品净额**：`N[s][p] = 产量[s][p] − 本槽消耗[s][p]`
  - N > 0：该槽对外供货；N < 0：该槽需运入（从有净余的槽取货）
  - 自动实现“本星能产则自给、不能产则运输”（用户 Q4）
- **变量**：`x[s][p] ∈ {0,1}`，40 槽 × 候选行星池（A5 过滤：排除母星/气巨/冰巨/O 型恒星行星；低开阔度 6 主题只对多槽产品开放）
- **约束**：
  1. 每槽恰好一颗星：Σ_p x[s][p] = 1
  2. 一槽一行星互斥：Σ_s x[s][p] ≤ 1（40 槽 = 40 颗不同行星）
  3. 低开阔度：槽数=1 的槽排除低开阔度行星；槽数≥2 的槽可用
  4. 母星保护区：G8 独占母星，其余槽不可选母星
  5. 附属品无变量（随宿主槽 0）
- **供给匹配（多源→多汇）用精确运输问题**：不是“每消费点找最近生产槽”的贪心；给定各槽净余/净缺与距离矩阵，求总运输成本最小的分配（规模 ≤3 源 × ≤10 汇，毫秒级）→ 与“总体运输时间最低”的目标一致

### B4. 目标函数 v2（趟当量模型，2026-10-26 定稿）

**距离口径（M1/M4 定稿）**：
- 同行星 0；同恒星系 = **1 趟**（固定；行星位置随时间变化，不做轨道级精确距离）；跨恒星 = **d_ly × w**（w=1，当前为内置常量）
- 不引入固定开销项（装卸对每个方案相同，不影响排序）

**总目标 = Σ(净额流量 × 距离当量)**，三类贡献：

1. **中间品槽间物流**：各槽净缺/净余按精确运输问题分配 → Σ N_flow(i,j) × dist(槽 i, 槽 j)
2. **母星 G8 原料物流**：石墨烯/光子合并器/框架材料（经钢钛合金）/氘核棒（重氢+超磁环+钛合金）/量子芯片/反物质/湮灭约束球/处理器/钛合金 → 母星
3. **氢物流（偏好项，不精确）**：气巨/冰巨 → 重氢槽（**260,800/min**）、G2 槽（能量矩阵 **128,000**）、卡西米尔槽（**393,216**）
   - 用户定位：只“稍微加强耗氢基地与氢主产地的关系”，权重可下调（`hydrogen_weight`，默认 0.5~1）
   - 产能不设约束（采矿科技可无限升级；轨道采集器初始 8 倍，每级 +10%）

**不计距离**：
- 采集品（14 矿/水/硫酸/有机晶体/临界光子）——分布在各行星，本星自采
- 顶级需求消费段：白糖就地研究（S18 产出即消耗）

**矩阵物流方向**（用户确认）：三色矩阵（G2）/信息矩阵（S16）/引力矩阵（S17）槽 → 白糖槽（S18）；反物质（母星 G8）→ 白糖槽；S18 是消费汇点（本身也是选址变量）

**不做**（用户明确）：同系内轨道距离（M4）｜合并装船（游戏无此功能，M5 撤销）｜行星容量约束（决策 2）

**后处理（可选，低成本）**：固定选址后用 LP 重分配各基地产量（运输问题），修正“均分”假设的偏差，报告“均分成本 / 重分配后成本”双值
