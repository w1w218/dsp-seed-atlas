# P3 地图搜索器方案（定稿 2026-10-19）

> ⚠️ 历史文档（2026-10-20 A2 后）：文中 "net8 搜索器引用 DspSeedFinder" 的架构已变更——
> 现为 `DspSearcher`（net48 + 游戏 DLL）+ `DspCore48` 权威引擎；本文保留作 P3 设计与评分规则参考。

目标：给定合并配比（宇宙矩阵 10万/min + 戴森球 2万帆/150火箭，3级增产），扫描种子空间
0~99,999,999，输出"星系能支撑的产线产量"最高的 top20 种子。

前置：P0-P2 已完成（星表/行星/地形/矿脉，存档对拍 197/198 + 199/200）。

## 1. 评分模型（瓶颈法）

- **固体矿 14 种**：星系全部行星 `VeinGen.GenerateVeins` 储量汇总（含恒星 resourceCoef、油 √coef），
  除以配比每分钟需求 → 该矿可支撑分钟数；全部矿种取 min = 星系支撑产量。
- **气巨气体**（每气巨按 GasItems×GasSpeeds 折算，采集站固定 40 = 游戏上限）：
  - 气态巨星（Gas 1/2/5）：氢 96% + 重氢 4%
  - **冰巨星（Gas 3/4）：可燃冰 70% + 氢 30%** ← 可燃冰供给 = 固体矿脉 + 冰巨星气体合计
- **水**：母星海洋无限，不计；**硫酸**：火山灰行星（Volcanic 1，WaterItemId=1116）提供，4.4 要求 6ly 内有
- **临界光子**：不计。
- 排名 = 支撑产量降序；并列看第二瓶颈。快筛用理论储量（组数×VeinOpacity×10万×resourceCoef，
  含距离加成 `7^logchain(dist/32)×0.6`），精算用全量地形+矿脉精确储量。

## 2. 过滤条件（全部在快筛阶段，按序淘汰）

| # | 条件 | 层 | 强制/优先 |
|---|---|---|---|
| 4.1 | O 星（spectr==6）≥3 | 星表 | 强制 |
| 4.2 | 黑洞≥1 且 中子星≥1，两颗中近者≤近阈值、远者≥远阈值（初值 8/15 ly，可调） | 星表 | **优先**（“4.2达标”展示列，不参与排序不淘汰） |
| 4.3 | 母星系（stars[0]）含冰巨星（Gas 3/4） | 行星 | 强制 |
| 4.3b | 母星为冰巨星卫星（母星 orbitAround 行星为冰巨星） | 行星 | 优先（加分） |
| 4.4 | 6 光年（以出生星=银河中心）内 13 资源全覆盖 + **火山灰行星（硫酸）**（单极磁石不算；水不计，母星自带） | 行星 | 强制 |

## 3. 两阶段架构

- **快筛**（全空间 0~99,999,999）：`CreateGalaxyLight`（仅恒星层，毫秒级）→ 判 4.1/4.2 →
  通过才生成行星层 → 判 4.3/4.4 → 通过才算理论储量并维护全局 top 池（500）。
  实测 32 线程 ≈ 1 万 seeds/s（全局队列 + worker 本地批处理 + ServerGC），全空间 ≈ 2.7 小时。
- **精算**（快筛 top 500）：全量地形+矿脉（27s/种子 ÷ 16 核 ≈ 14 分钟）→ 精确储量 → 最终排序。
  理论 vs 精确：瓶颈矿 <2%、稀有矿 ±4~6%；top20 重合 19/20（排序影响小，但精算给出可核对的真实储量，保留）。

## 4. 并发与断点续跑

- **全局种子队列**：生产者顺序分发 nextSeed → `ConcurrentQueue` → N 个工作线程取种子运算（线程数=配置）。
- **checkpoint**：每 10 万种子持久化 `search-checkpoint.json`（已分发位置、top 池、过滤统计、参数回显、
  累计时长）；暂停/停止时同步写。`--resume` 从断点继续（最多丢一个块）。
- 精算阶段同样支持 checkpoint（top 池常驻）。

## 5. 产出

任务目录 `dsp/src/search-out/<时间戳>/`（GUI 或 headless 均同）：

**执行中**
- `search-checkpoint.json`：断点（NextSeed）+ top 池（500）+ 过滤统计（10 万种子/次；暂停/停止/断点续跑）
- `search.log`：日志（进度心跳/检查点/错误），GUI 与 headless 均写任务目录

**执行结束（精算后）**
- `results.csv`（主交付）：池内全部候选按精算支撑降序——排名/种子/支撑小时/瓶颈/第二瓶颈/
  6ly丰富度（高·中·低，稀有矿 9~14 总储量池内三等分）/6ly均衡小时（稀有矿按配比 min 储量÷需求，与支撑同口径）/
  冰巨卫星数（含母星）/最近O星(ly)/黑洞·中子星(ly)/4.2达标/O星数/6ly行星数/氢·重氢·可燃冰气速率(min)/
  14 矿储量（亿）
- `refined-detail.csv`（程序读/重分析用）：行星级精算明细（恒星 id/距离/类型/光谱、行星 id/主题/气巨/卫星母/6ly内、14 矿组数+储量）
- `search-report.txt`：参数回显、范围、总耗时、命中率、各过滤条件淘汰分布、TOP20 段

## 5b. 分析字段（精算后计算）

- 6ly丰富度：6ly 内稀有矿（9~14，不含可燃冰——另有气巨气体来源）总储量；池内三等分 高/中/低
- 6ly均衡：min over 稀有矿（6ly 储量 ÷ 配比需求/min）→ 小时（与支撑时间同口径，聚焦前期稀有矿是否平衡）
- 冰巨卫星数：母星所绕冰巨星的卫星总数（含母星，限定同恒星——number 为恒星内独立编号）
- 最近O星距离：母星在银河中心 → 最近 O 型恒星距离（快筛阶段顺带计算）

## 6. 工程结构

- **`DspSeedFinder`**（改造，仍是控制台 + 类库双用）：`UniverseGen.CreateGalaxyLight`（星表层生成，随机流一致）、
  生成 API 收口。
- **`DspSearcher`**（新建，.NET 8 WPF，独立工程，项目引用 DspSeedFinder 生成代码）：
  - `Core/`：SearchConfig、Filters（4 条件）、TheoryScorer、Searcher（全局队列+多线程+checkpoint）、
    Balance（读 balance.json）、ResultModels
  - `UI/`：MainWindow（条件面板 + 进度条/状态 + 实时 top 表格 + 日志区 + 开始/恢复(读检查点)/停止）；
    也支持 `DspSearcher.exe --headless --from/--to/--threads/--resume` 无窗口运行
  - `data/balance.json`：合并配比固化（矩阵 10万/min + 戴森球，数值来自 data/combined-balance.md）；气巨采集站固定 40（游戏上限）
- 不引用 DspFindSeed-3.1 / 游戏 DLL。

## 7. 验证

- seed=1 快筛跑通：4.1/4.3/4.4 判定与手算一致；星系理论储量 vs 存档解析汇总口径一致。
- 精算衔接：理论 top50 → 精算后排位移动 ±0~4 名、个别大跳（稀有矿瓶颈）；top20 重合 19/20（种子 5648 支撑 4322 vs 4321 分钟）。
- 断点：跑一小段 → 停止 → resume 从断点续，进度不重复不丢失（worker 停止信号 <4s 响应）。
