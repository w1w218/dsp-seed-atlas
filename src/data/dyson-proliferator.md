# 戴森球建设 × 3级增产剂优化（src\data\dyson-proliferator.md）

脚本：`src\tools\dyson_proliferator_lp.py`（LP，机制与 matrix-proliferator 相同）。
目标：太阳帆 20,900/min（含组件内部 900）+ 小型运载火箭 150/min。
权重：煤=1 金伯利=1 刺笋=1.5 有机晶体=2 光栅石=3；铁/铜/石/钛不限制；其余资源 ≤ 无增产基线。
路径：光子合并器=棱镜 R68（省光栅石）｜石墨烯=可燃冰｜碳纳米管 1:1｜卡西米尔 1:1｜金刚石=金伯利（增产剂 Mk.II 用）｜重氢采集优先+分馏。

## 修订（2026-10-17）：煤不设上限

用户确认：增产剂引入的煤消耗视为合理消耗，**煤矿不再受“≤基线”约束**（目标权重仍计煤=1）。
重跑后：Mk.III 143→**1,139/min**、喷涂 8,578→68,326 次/min、加权目标 33,242→**25,689（-22%）**；
全喷方案因无煤上限变为可行，但目标 33,393 仍高于最优（喷过量得不偿失）。

## 氢 / 重氢结算（戴森球链的关键自平衡）

- 石墨烯（可燃冰裂解）副产氢 = 卡西米尔需求 + 重氢分馏耗氢，**正好自平衡**（氢采集 0）。
- 重氢：需求 4,800/min，LP 选择 **采集 2,382 + 分馏 2,418**——分馏 1:1 耗氢，恰好消化石墨烯裂解的氢副产盈余，即分馏是"免费"的重氢来源。若气巨采集更多，分馏相应减少（分馏≤4,800 皆可，只是氢盈余会改为过剩/发电）。

## 备注

- 未计电磁弹射器/垂直发射井耗电与戴森云容量（下一步设施/电力）。
- 煤放开后太阳帆已转喷（21 条喷涂之一）：其省下的可燃冰/硅石/铜等远超增产剂耗煤。仍不喷的多为铁铜钛/玻璃/光子合并器等“便宜”链（石矿不限），以及燃料棒/磁场环/钢材等喷涂点少收益低者。
- 与矩阵链共享的中间品（卡西米尔/碳纳米管/量子芯片/处理器等）按各自链最优喷涂；实际建造取"任一条链要喷就喷"（更省料，无冲突）。
