# 宇宙矩阵物料配比（src\data\matrix-balance.md）

计算脚本：`src\tools\matrix_balance.py`（配比模型 + 可调参数），配方/物品数据来源 `src\data\json\`。
目标：**每 1 个宇宙矩阵** 的全部原材料需求与氢/重氢/临界光子结算。
路径选择由用户 2026-10-16 确认。

## 氢 / 重氢结算（关键平衡）

- 氢需求 14.000 = 能量矩阵 2 + 卡西米尔晶体 12（R28/R29 各 6）
- 氢副产 4.750 = 精炼油 R16 1 + 可燃冰分解 R32 2.75 + 反物质 R74 1
- **净缺口（采集）9.250/个**
- 重氢需求 5.000（奇异物质 R104 需重氢 10，×0.5 次）——当前假设**全部由分馏塔**提供（采集量参数=0），分馏耗氢 5.000
- **氢最终需求 = 9.25 + 5.00 = 14.250/个**（1/min 为 0.950）
- 若气巨直接采集重氢 n 个/个，则分馏氢扣减 n（重氢采集可显著降低氢压力）

## 备注

- 铁=29 的构成：铁块 20（电路板7+电动机8+齿轮4+奇物1）+ 磁铁 9。
- 配比是纯线性的：目标 x 个宇宙矩阵 = 表中数值 ×x；1/min 换算系数 60/900=0.0667。
- 可调参数（改 `matrix_balance.py`）：碳纳米管路径权重、卡西米尔路径权重、重氢采集量。
- 不含设施/电力/塔/研究站建设成本；含反物质与引力矩阵"产 2"折算。
