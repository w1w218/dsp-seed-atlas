# 戴森球建设配比（src\data\dyson-balance.md）

脚本：`src\tools\dyson_balance.py`。目标：**太阳帆 20,000/min + 小型运载火箭 150/min**。
数据源：`src\data\json\`（现行版本配方，含戴森球 DLC 链）。

口径：太阳帆总需求 = 20,000（戴森云）+ 900（火箭链组件内部）= **20,900/min**；
火箭 150/min → 戴森球组件 300、氘核燃料棒 600×（R41 产 2）。

## 路径选择（新链）

- 光子合并器 = **R68 棱镜路线**（棱镜×2+电路板×1，省光栅石；备选 R69 光栅石×1）
- 石墨烯=可燃冰 R32、碳纳米管 刺笋:石墨烯=1:1、卡西米尔 钛晶石:光栅石=1:1（同矩阵链）
- 钛化玻璃=R30、处理器/量子芯片/位面过滤器=矩阵链同款
- 重氢：先采集，不足分馏（1:1 耗氢）；氢：副产优先，不足采集

## 关键平衡点

- **氢几乎自平衡**：可燃冰裂解（R32×7,400/min）产氢 7,400，卡西米尔（R28/R29×300 次）耗氢 7,200 → 净 -200/min（略过剩，不必采集/可发电）。
- **重氢 6,000/min** 为火箭链最大"采集品"之一（氘核燃料棒 R41 ×300 次 → 每 2 棒耗重氢 20）。若改分馏（1:1 耗氢），氢需求 +6,000（此时氢不再过剩）。
- 光栅石 2,400/min 全部来自卡西米尔光栅版（1:1 配额）；如光栅石紧张可改为全钛晶石版（有机晶体/钛需求上升）。
